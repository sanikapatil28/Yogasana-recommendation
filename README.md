# 🧘 YogaSutra AI – AI Based Yogasana Recommendation

YogaSutra AI is a web-based **AI-powered Yogasana Recommendation System** that recommends suitable yoga exercises based on the user's selected goal and profile.

The application combines traditional yoga concepts inspired by **Patanjali's Yoga Sutras** with a rule-based recommendation approach and a modern web application.

---

## 📌 Project Overview

YogaSutra AI helps users select suitable Yogasanas, Pranayama, and Meditation practices according to their fitness goals.

The system provides:

- User Registration and Login
- Personalized Yoga Plan Generation
- Yogasana Recommendations
- Pranayama Recommendations
- Meditation Recommendations
- Yoga Plan Details
- Yoga Pose Instructions
- Benefits and Precautions
- Session Completion Tracking
- Practice Streak
- User Profile
- Admin Login
- Admin Dashboard
- Yoga Knowledge Management
- User and Plan Management

---

## 🎯 Project Objectives

The main objectives of YogaSutra AI are:

1. To provide personalized Yogasana recommendations.
2. To connect traditional Indian knowledge with modern computer science.
3. To provide users with suitable yoga practices according to their goals.
4. To provide information about the benefits and precautions of yoga.
5. To maintain user yoga plans and practice sessions.
6. To provide an administration panel for managing the application.
7. To demonstrate an AI/rule-based recommendation system using Python.

---

## 🧠 AI Recommendation System

YogaSutra AI uses a **rule-based recommendation engine**.

The recommendation engine considers user information and selects suitable yoga practices from the available yoga knowledge base.

### User Inputs

The system can use information such as:

- Age
- Fitness Level
- Health Goal
- Stress Level
- Yoga Experience

### Available Goals

Currently, the application provides two main goals:

- **Weight Gain**
- **Weight Loss**

### Recommendation Output

The generated plan contains:

- Yogasanas
- Pranayama
- Meditation
- Recommended duration
- Instructions
- Benefits
- Precautions

## 👤 User Features

### Registration

New users can create an account by providing their required details.

### Login

Registered users can securely log in using their email and password.

### Dashboard

The dashboard displays:

- Today's Yoga Plan
- Current Streak
- Total Sessions
- Goal
- Recent Activity
- Practice Minutes
- Generate AI Yoga Plan option

### AI Yoga Plan

Users can generate their personalized yoga plan using:

**Generate My AI Yoga Plan**

The system selects suitable Yogasanas, Pranayama, and Meditation and saves the generated plan.

### Yoga Plan Details

Users can view detailed information about each recommended Yogasana, including:

- Yoga image
- How to Do
- Benefits
- Precautions

The plan also displays recommended Pranayama and Meditation.

### Session Tracking

Users can mark their daily yoga session as completed.

The application tracks:

- Completed sessions
- Practice activity
- Current streak

### Profile

Users can view their account information from the profile page.
